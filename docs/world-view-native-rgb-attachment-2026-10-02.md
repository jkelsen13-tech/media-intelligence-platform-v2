## Pixel orientation

The transport's decoded upload contract is `cesium-imagebitmap-preflip-y-v1`: `createImageBitmap` uses `imageOrientation:'flipY'`, `premultiplyAlpha:'none'`, `colorSpaceConversion:'none'`. Installed Cesium 1.145's public Texture API defaults `flipY` to true (`@cesium/engine/Source/Renderer/Texture.js`) and calls WebGL `UNPACK_FLIP_Y_WEBGL`; ImageBitmap upload does not apply that flag. A decode with `none` inverted each geographic tile in actual App screenshots. Preflipping at decode preserves the received north-up geographic pixels without an extra retained canvas or changed PNG/source geometry.
