## Reader contract and clocks

`read_reviewed_public_article_v1(article_id, public_version_id?)` returns an admitted immutable source envelope or null. `read_reviewed_public_story_v1(story_id, public_version_id?)` returns the canonical subject and exact member envelopes. Default reads select the highest sequence before checking visibility; they never resurrect an older visible version when the head is invalidated. Explicit historical versions still require present authorization for their source and nested evidence.

`read_reviewed_public_story_for_article_v1(article_id)` returns a single unambiguous current Story or null. The plural sibling returns a deterministic bounded list of up to 100 current matches, and null if the bound is exceeded. The keyset Story directory returns at most 30 heads per page with completeness and a next cursor. Independently fetched pages and material contexts are not a global atomic snapshot. The browser backend uses the current SDK session, has no result/session cache, validates scope and bounds, and aborts requests at 15 seconds.

| Clock | Meaning |
|---|---|
| `published_at` / Source Report `report_time` | The publisher's recorded publication clock. No event-effective time is inferred. |
| `fetched_at` | The article's original fetch clock, explicitly labeled `article_original_fetch`; later capture ingestion does not update it. |
| `captured_at` | Exact retained-capture observation clock. |
| `reviewed_at` | Database recording time of this explicit owner binding, after the source/member checks. |
| `visible_at` | Public mapping recording time; distinct field even when the same transaction records both. |
| Source Report `fetch_time` | Null: there is no retained exact fetch observation for a correction capture. Retention and original article fetch are separately named. |
| Event effective / material-change / acknowledgment | Owned by the Story/material declaration and Following extensions, never derived from fetch age here. |

The parser reuses `inspectionTime.js`: explicit timezones and valid calendars are required, supplied timestamp text is preserved, and ordering retains nanosecond precision. Sequence numbers are canonical decimal strings, never unsafe JavaScript numbers. A private newer capture yields only `pending_revision: true`; its ID, hash and bytes are not disclosed without an explicit report/proposition decision. Original history survives correction and withdrawal. Every source envelope explicitly reports `is_current_source_version` and a nullable visible `superseded_by_public_version_id`. An older Story member may remain an authorized historical snapshot; a newer source head never silently rewrites that member. Its superseded flag must be shown and must not establish current Breaking urgency.

Public search uses `search_reviewed_public_article_ids_v1(query, limit <= 100)`. It searches only frozen public titles/summaries and exact admitted evidence excerpts. Source Reports provide their permitted titles/summaries; their private capture body never becomes a search oracle. An unreviewed body-only term is absent; an explicitly reviewed body-span term can match. The endpoint returns IDs and completeness, never capture body text. Exceeding the bound returns no partial IDs and `complete: false`; the SDK exposes an unavailable scope, never a fabricated complete negative or truncated feed. Full-capture search would require a separate source-version-bound permission owner. Native News q searches use these IDs in the same reviewed projection; the parent's ancillary readers must use the same scope when comparing source metrics.
