# Selective execution exact catalog guard — 2026-10-02

The source proposal now compares a separately supplied fresh canonical catalog before creating any table/function/index/sequence or changing any ACL. It locks existing prerequisite tables, rejects a missing/drifted baseline, refuses every named new target collision, and requires the existing private pipeline schema owner. No existing native function or view is replaced. All same-name overloads across every schema are included so unrelated definitions, owners and ACLs cannot drift unnoticed.

The catalog includes all evidence-pipeline relations and routine names, public native `mip_` routines and their cross-schema overloads, relevant public source/profile/configuration relations, all user schema ownership/ACLs, all default privilege entries, and every role's authority/configuration/membership options. Relation metadata includes canonical sorted privilege tuples, columns/types/default expressions/identity/generated properties and column ACLs, RLS/force-RLS, policies and role names, constraints, trigger definitions/native bodies, view/index definitions and sequence configuration. Sequence bigint values are strings, preserving exact values through JavaScript JSON round trips. Database, server version and installer identity are pinned. The catalog excludes mutable table data and sequence last values.

Collision refusal covers the six tables and their composite/array types, primary/unique indexes, the explicit discovery index, both identity sequences, and both exact new function signatures. Unrelated function overloads are allowed only as unchanged pinned native/sentinel objects; their owners, definitions and ACLs are never swept by grant/revoke/drop statements. Freshly pinned unexpected default ACL grantees are rejected before creation. Known reader defaults on the two new sequences are explicitly revoked; service usage/select is the only producer grant added to those exact sequences.

The installed `preflight.sql` requires a separately pinned installed result in `mip.selective_execution_preflight_expected_catalog` before showing metadata.
