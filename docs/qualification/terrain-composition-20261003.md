The current USGS research candidate has parent-reported, inspected native DEM bytes, but the worker has no TIFF custody and its viewer-height transform, exact capture, horizontal realization and ortho registration remain unresolved. This isolated change adds a pure planning validator that keeps those facts inspectable while holding production composition. It adds no active provider integration.

Base commit: `ca72a6df511bbb26c6b9e0a193a3e0baf01aa428`, tree `cbcfc510a117101fd163f83b3c574dd979085b02`. Branch: `codex/mip-terrain-contract-20261003`. The parent owns integration and independent Cursor review.

`evaluateWorldViewTerrainComposition({source, composition})` returns separate `researchInspection` and `productionComposition` outcomes, copied frozen source facts, rejection reasons and a detached plan only when all planning declarations qualify. It consumes explicit receipt declarations; it does not authenticate the issuer or verify underlying asset bytes itself. Production authority remains external. A positive fixture uses `SIMULATED` admission authority, yielding `SIMULATED_PLAN_QUALIFIED` with real production qualification false. Returned results always retain permissionGrant/sourceAdmittedByThisValidator/providerActivated/transformExecuted false and preserve canonical anchors and evidence precision.

The source declaration requires a bare-earth DEM identity, HTTPS provider provenance/version/reference, explicit lineage conflicts, SHA256 and byte length bound to a custody receipt, CRS/datum/axis/units evidence, finite ordered native bounds, a single Float32 band and native resolution, a missing-value policy and a verified or explicitly unknown capture clock. Parent-reported custody can support research inspection. It cannot qualify production composition.

Production planning requires consumer custody, resolved lineage/horizontal realization and epoch, qualified vertical evidence and source geoid lineage, an asset-footprint capture clock, asset-bound admission and rights references, a native requested footprint inside the retained source footprint, and a declared WGS84 ellipsoidal metre target. Both horizontal and vertical operations must carry an approved receipt, exact model/version, source/output bases including units, and coverage containing the entire request in the native source CRS. Identity operations carry the same explicit receipt requirements. No model is selected or inferred by this contract. Constant geoid/point-offset shortcuts and missing/mismatched receipts fail closed.

Ortho registration must bind the terrain hash and a separate ortho hash, both horizontal references, a QA reference and the covered native footprint. DEM-derived roof, facade or building-height claims, evidence precision promotion and canonical anchor movement fail closed. Nodata must remain missing; zero fill or interpolation cannot masquerade as measured elevations. This helper does no pixel conversion, reprojection, vertical transformation or resampling.
