# Terrain operation/grid correction — 2026-10-03

The original detached contract could accept approved model/version/reference declarations without binding operation accuracy or grid availability. Contract `mip-terrain-composition-v2` now requires those facts on both horizontal and vertical operations. The original `7ec5e6235fc0a562a0a6c302dcdd6dbc6ca310dc` qualification remains historical evidence for its narrower v1 scope; its six receipts and documents are unchanged.

Every operation carries `operation:{id,reference,accuracy:{status:'qualified',basis:'operation-error',value,units:'metre',reference}}`. The value must be finite and nonnegative; missing or unknown accuracy, unsupported units and a datum-accuracy label fail closed. These are explicit stated operation-error declarations, not an inference about source measurement or datum accuracy.

Every operation carries `gridRequirement:{kind,qualified:true,reference,inventory}`. A required inventory must contain unique grid IDs, exact versions/SHA256 hashes, verified available custody references and native CRS coverage containing the entire composition footprint. Missing, unavailable, unknown, unverified, duplicated or incompletely covered grid declarations fail. A genuinely grid-free operation instead declares `kind:'none'` with a qualified reference and an empty inventory. No grid is inferred or downloaded.

Identity operations require exactly equal source/output bases, an explicitly qualified empty no-grid requirement and stated zero operation error. Unknown source/datum accuracy stays unknown. The contract accepts no constant point/geoid offset or arbitrary inline shift parameters, including nested operation shifts. Exact operation records remain external declared evidence; this pure validator is not a security boundary or a transform executor.

All positive operation, accuracy, grid and admission declarations remain explicitly **SIMULATED**.
