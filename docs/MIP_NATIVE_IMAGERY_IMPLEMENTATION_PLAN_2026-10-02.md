### Existing ownership and exact boundary

Its flow is `plan → estimate → reserve → transport.load → renderer.attach → observe → release`. There is no existing `renderer.clear` call. Clearing means aborting pending work and disposing the render handle, then the loaded handle, with an idempotent reservation release. It retains at most one active source request. ### Narrow interface and payload binding

The proposed signatures and required fields are frozen in the retained `interface-contract.json`:

- `adapter.attachSourceImagery(loaded, descriptor, {signal}) → Promise<{observation, dispose}>`.
- `adapter.getSourceImageryState() → detached JSON state` with capability, adapter generation, layer counts, exact source/hash/bounds/LOD, request successes, native frame observation and footprint screen scalars.
- `controller.invalidateAttachment(reason) → snapshot` cancels pending work and clears active metadata/handles, retaining the local accounting session.
- The `WorldMapCanvas` facade implements the existing `renderer.attach` contract by delegating to `attachSourceImagery`. The positive test never substitutes a renderer, leaks a private viewer or fabricates ACTIVE metadata.

The loaded contract identifies the source, the registered asset hash, exact runtime provenance digest, four or fewer unique tile descriptors, encoded hashes and lengths, decoded dimensions, actual geographic rectangles and real LOD. Its bitmap objects are resources, not admission flags. The native adapter revalidates this binding before allocation against the frozen admitted descriptor and packet. A hash, source, bounds, size, tile count or LOD mismatch refuses the entire candidate; no partially attached source becomes active. The four Ohio PNGs are RGB with no alpha/NIR/height semantics, so their provider advertises no alpha channel.

The first implementation supports one nonwrapping EPSG:4326 packet rectangle, with the exact union of its partitioned tile rectangles equal to the descriptor bounds. It loads the whole bounded packet; it does not invent arbitrary cropped or dateline coverage. Request bounds describe that actual payload footprint, not the entire viewport. Registry, packet and loaded handle use the same canonical numeric tuple without late rounding or an epsilon that silently expands admitted coverage. A larger viewport can show the baseline outside this footprint.

The package ZIP's hash is an already locally verified package identity; loading its member PNGs does not independently rehash the ZIP. The pinned runtime provenance bytes establish the member map. The loaded receipt must report which bytes were fetched and hashed in this App run and which package/original identities came from the preserved consumer proof. It cannot mark the original TIFF decoded or verified locally.

Use a small provider implementing Cesium's public ImageryProvider interface over already decoded `ImageBitmap` objects. Each tile has a one-by-one `GeographicTilingScheme` over its own exact EPSG:4326 rectangle, minimum/maximum level zero, real dimensions, credits and an error event. `requestImage(0,0,0)` returns that supplied image; it performs no fetch. Unsupported tile/level and terminal cancellation refuse without a new provider request. Feature picking is unsupported. Do not write Cesium's private `_image` field or call `SingleTileImageryProvider.fromUrl` on a network URL, which would introduce an unreserved second fetch/decode outside the transport.

### Lifecycle and actual render observation

Reserve before streaming or decoding. Validate all descriptor/packet limits before allocation; stream sequentially with exact per-artifact and cumulative encoded caps; refuse redirect, unexpected origin/path, short/long bytes, bad PNG/hash/dimensions and abort. Decode only hash-verified inputs using an explicit orientation/alpha/color conversion policy. Qualification samples verify the browser's decoded RGB semantics against the preserved known samples; no screenshot color is treated as raw geodetic evidence.

Both transport completion and native frame confirmation need a bounded deadline (15 seconds for this local qualification), composed with the owner AbortSignal. Abort never creates an automatic retry. Native attachment refusal before readiness/unsupported renderer happens before transport through the orchestration capability guard. A frame deadline cannot leave a pending lease, reservation or partial overlay alive.

The render handle owns its native layers, observation subscriptions and one bitmap lease. The transport owns the original bitmap lease. On ordinary disposal the adapter removes only its own layers, unsubscribes and releases its lease, then the controller releases the transport lease. If native failure requires deferred teardown, a terminal generation prevents future requests/publication immediately, while the adapter lease keeps decode resources valid until the existing deferred native cleanup completes. The final lease closes each bitmap exactly once. No Promise returned by a disposer is assumed to be awaited by the existing controller.

Native success requires actual provider image completion for matching tile identities, an owned live layer set, visible source credits and a subsequent native frame on the same adapter generation. Attachment or renderer readiness alone leaves source state unconfirmed. The current ACTIVE resolver only establishes observed source success, not every viewport pixel; retain `viewportCoverageQualified: false`. The four-tile positive fixture must observe all four supplied image identities and verify a photographic pixel difference in their projected footprint before its stronger four-tile receipt passes.

Keep one existing baseline imagery layer and at most four photographic overlay layers: maximum five imagery layers in this adapter. Do not make the local photograph the first/base imagery layer, where a small rectangle can be stretched across the globe. If the baseline layer is absent, refuse attachment until the baseline is valid. Replacement removes the previous owned overlay before adding another set; late disposal removes only the late handle's own set. Outside the actual footprint, the baseline/ellipsoid remains visible. No geometry, terrain, building height or facade is inferred.

Before stack switch, native fatal failure, adapter destroy or Map/Graph remount, invalidate the controller attachment and mark overlay state inactive. On new native readiness, a new request can reserve only under the existing active session and admission checks. Atlas and MapLibre perform no RGB transport/allocation and cannot publish photographic ACTIVE. Native hidden/idle transitions use the existing controller cleanup and abort rules. Meaningful user interaction alone can start a fresh session after the existing prolonged-idle terminal disposal; changing stack, context, time or test configuration cannot reset allowance.

Bind a request-context generation to selected canonical object/version, recorded inspection time and native adapter lifetime. A context/time change invalidates pending and active attachment ownership before a new request, so late decode/provider/frame callbacks cannot publish under the replacement context. This generation is an orchestration token, never a new canonical identity or evidence time. A new view time does not change the source's fixed capture day, fabricate historical image matching, or upgrade the unchanged synthetic event point's unknown datum.

### Resource and source scope

The default guard is 16,777,216 bytes, 32 source reservations and two concurrent pending reservations. It is a local source-work allowance, not account/provider billing or an OS/GPU memory limit. Release conservatively consumes `max(estimate, observed transport bytes)`; it does not refund allowance when images/layers are disposed. Retained decoded resource scalars and imagery-layer counts must be recorded separately from cumulative transport/allowance.

For the received Ohio package, the preserved ZIP is 2,918,432 bytes and retained RGBA is 4,194,304 bytes. A conservative reservation is 7,112,736 bytes. The four PNG GETs contain 2,871,856 bytes; this number is not the ZIP length. Two conservative loads consume 14,225,472 bytes; a third in the same session must refuse and display the cheap fallback. Known decoder staging/copies must fit the chosen bounded allocation policy; any retained duplicate decoded buffers or extra generated imagery require a larger explicit estimate and may make even two loads unavailable. Browser/driver texture copies, process RSS and physical-device performance are outside this guard's claimed measurement.

The runtime footprint remains the explicitly reduced WGS84 rectangle in `payload-reference.json`. Capture is `2023-03-07`, day precision, ground-condition meaning. The locally received derivative was decoded; the original full TIFF/archive identities remain upstream provenance. The quoted 1 m transformation operation accuracy and original XML's 11 cm RMSEx/RMSEy / 27.6 cm 95% specification remain separate, neither is measured registration. The existing synthetic point has unknown datum and stays unregistered. Camera floors, canonical coordinates, evidence precision and inspection context are unchanged by the imagery integration.
