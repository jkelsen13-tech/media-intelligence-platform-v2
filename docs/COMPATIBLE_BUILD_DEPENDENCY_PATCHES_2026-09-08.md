# Compatible build dependency patches — 8 September 2026 UTC

This bounded follow-up to [dependency triage](CI_DEPENDENCY_ADVISOR_TRIAGE_2026-09-08.md) changes only two existing development dependency records in the lockfile: PostCSS 8.5.16 → 8.5.28 and Nano ID 3.3.15 → 3.3.18. No production package, root manifest, major version or other lock entry changes.

The lock was generated by npm in an ephemeral GitHub runner using package-lock-only and ignore-scripts. No project files were stored on the owner's device. The preparation workflow is removed from the final tree. Registry tarball URLs and integrity hashes come from npm; they were not invented or bypassed.

## Verification scope

Regression tests exercise implicit source-map loading without an input path, parent traversal and symlink escape, while retaining normal adjacent-map behavior. Bounded subprocess tests verify zero/negative Nano ID sizes terminate in both ESM and CommonJS entries and ordinary IDs still work. The five-second subprocess timeout prevents a future vulnerable downgrade from hanging CI.

Required gates: full tests and builds on Node 22/24, current dependency audit, and the existing 320/390/1280px built-app browser preview. Package and lockfile changes now trigger that preview so build-tool changes get responsive runtime coverage. Final results and post-merge live checks are recorded in the PR.
