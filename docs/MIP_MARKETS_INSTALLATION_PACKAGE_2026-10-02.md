## Exact installation and recovery artifacts

- `supabase/source-proposals/markets-directory-v2.sql`: unapplied transactional package, full relation/column/owner/ACL/RLS/policy/trigger/function/role/membership baseline, exact existing history/review owner preflight, native history extension, private append-only qualifications/revocations/source bindings, current source/rights joins and bounded public reader.
- `scripts/marketsDirectoryPackage.mjs`: extracts the exact catalog preflight query and installs the package **only into a caller-supplied disposable fixture**. It reads no environment credentials and makes no remote request. Its captured test baseline is not authority to populate a live expected-catalog setting.
- `supabase/source-proposals/markets-directory-v2-rollback.sql`: empty-package recovery, using exact signatures and RESTRICT drops. Retained Markets/rights records or review rows cause refusal; preserving populated evidence requires a separately reviewed recovery plan. The fixture verifies exact original catalog restoration after empty rollback.
- Shared dependency: `supabase/source-proposals/public-reviewed-versions-v1.sql` and its private review helpers, owned by the public-version lane. Existing change-queue/assessment SQL must already be present. No migration ledger entries, jobs, source tables, existing review states or publication policies are replayed by the Markets package.

Before any separately authorized protected installation, pin the actual target/project, candidate and file hashes; obtain and review the fresh complete catalog using the package query; set `mip.markets_expected_catalog` to the **approved** exact baseline; confirm the expected existing record-kind constraint and reviewed-owner/native-assessment definitions; review public RPC definer ownership and fixed empty search path; verify zero public/ingestion-service review-writer grants. The installer refuses missing/drifted baselines, wrong owners and an occupied RPC name, including an unrelated overload. All grants/revokes address exact function signatures. No broad same-name ACL loop is used.

The reader uses the calling statement's PostgreSQL snapshot (`STABLE`), original explicit-zone inspection text, exact integer-nanosecond comparisons, a content-derived directory version, at most 1,000 retained identities/200 assets/200 paths and a 2 MiB response ceiling. Pending/private/revoked source decisions never become eligible through RPC flags. It returns unavailability on malformed scope or read failure. Complete source text is kept private; public captures contain only exact owner-admitted spans. Historical inspection is relationship valid-time inspection of current qualified retained decisions, **not** an as-known-then reconstruction.
