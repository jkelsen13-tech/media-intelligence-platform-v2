## Implemented read and lifecycle contract

`createMarketsBackend(client)` has no global-client fallback, no construction read, cache, poll, caller identity mapping or provider access. `loadDirectory({at})` requests only `read_markets_source_directory_v1({p_at: at})`. A null clock asks the future owner for its qualified source snapshot; a non-null clock must be a real explicit-zone instant. Caller text is preserved, with exact instant equivalence checked against the response. Date-only/invalid clocks perform no request.

The installed PostgREST builder receives an AbortSignal. A fixed **15-second** timer aborts the fetch and a bounded race ends unavailable even if transport stalls; the timer is cleared on every completion/exception. Clients without installed-builder abort support fail closed. No timeout option, automatic retry, polling or provider request is added. The SDK remains responsible for parsing its response; the **2 MiB limit is on the parsed projection's serialized size, not a claimed network-byte cap**. Existing directory limits (200 assets/paths, typed versions/aliases) and evidence validation remain separate. Invalid, denied, missing or wrong-clock results never substitute demo assets or prices.

`useMarketSourceSnapshot` starts a read only on Markets entry or a changed ready-session/client/inspection scope, unless an explicit supplied projection exists. It ignores late completion after navigation, scope/client change or unmount. Render-time scope checks withhold former data before effects run; inactive scope/client changes also erase the hidden old snapshot so returning to a former account/clock cannot resurrect it. A completed qualified snapshot can survive compatible view navigation under its recorded scope. Returning to Markets refreshes through the same bounded reader.

The asset source selection catalog is pending while loading. It qualifies capture IDs only against the selected typed asset's validated paths when the result arrives; a completed missing/error/invalid/timeout result clears invalid source hints with the existing fallback disclosure. It never adopts graph-company sources as asset authority. Source status distinguishes loading from completed unavailability. Quote, retrieval, event occurrence, publication, observation and valid-time meanings remain with their existing owners; no price appears.
