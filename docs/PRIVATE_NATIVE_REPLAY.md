# Private offline replay contract

The generator runs pure native deterministic primitives without persistence, paid calls or external connections. It does not invoke EntityResolver or approved-event projection. The existing source-lineage foundation is a design brief, not an executable primitive; URL/hash overlap remains machine-detected evidence with unresolved independence.

Run `node scripts/generatePrivateReplay.mjs` and stream a single JSON object followed by a newline on stdin. It processes the first line immediately without waiting for EOF. The object has `records`, exactly 93 distinct capture and candidate records. No raw input file is required. Output logs contain counts, revision hash and fixed output path only; errors never contain input values.

Each record contains the original `article_id`, `capture_id`, `candidate_id`, `content_hash` (retained receipt/database capture-payload hash; never recomputed from the field text), `span_start`/`span_end` (Unicode code points), `field_name`, `field_version`, `exact_excerpt`, `url`, `topic`, and optional `outlet`, `title`, `published_at`, `source_date`, `origin_id`, `dependency_id`. Required gates: `rights_mode: "bounded_exact_excerpt"`, `candidate_state: "pending"`, `publication_allowed: false`, `public_admission: false`. Optional `captured_field_text` exists only transiently to verify the exact span. It is never emitted. The capture-payload hash remains retained/unverified because the field text is not the canonical payload. Without it, binding is incomplete, not verified. Failed span inputs remain counted but text is quarantined from analysis. Excerpts are capped at 12,000 code points; stdin is capped at 32 MiB.

The generated `.private-demo/native-replay.json` is gitignored. Only the explicit `build:demo` Vite target copies it to ignored `demo-preview-dist/private/native-replay.json`; the ordinary production build has no copy hook or replay imports. Never deploy the private output publicly. Use only a Preview host whose existing authentication covers every asset. Output-local `vercel.json` requires private/no-store response headers; the page permits same-origin loading and blocks external connections. Header configuration does not provide authentication by itself.

The browser fetches the same-origin static path `/private/native-replay.json` with no-store and validates all candidate IDs, hashes and spans against the frozen receipt universe. Missing, malformed or mismatched artifacts produce the existing receipt-only view. The artifact is never included in JavaScript bundles.

Native sentence extraction retains its 40–400 character sentence and six-claim bounds. It produces text/kind only, never invented SPO. Native lexical grouping uses 0.6; shared/unique is adapted to capture membership and is not a truth or independence claim. `computeComparison` omission means absence within native extracted bounded sentences only; thin extraction yields coverage unknown. Its historical `independent_outlets` field is deliberately discarded. Entity-overlap uses at least two normalized unresolved mention strings with the native 30-day window where publication timestamps exist. Cluster transitivity and undated matches require review. No cluster is an accepted event or relationship.

The baseline is constructed for qualification: the input receipt identities with zero replay-derived artifacts. The current revision is content addressed. What Changed compares these isolated artifacts only, never fabricated historical production state. Every propagation family receives an explicit derived-pending or unavailable receipt. Unsupported hypotheses, assessments, accepted relationships and canonical identities remain unavailable.

Tests and browser fixtures contain synthetic text only. Do not commit generated private artifacts, raw input, screenshots of private text or `pnpm-lock.yaml`.
