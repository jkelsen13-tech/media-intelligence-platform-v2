# Private retained Markets qualification — work in progress

This opt-in package extends shared public.nodes/public.edges identities and evidence_pipeline history/candidates in a disposable native fixture. It does not deploy a Markets tab, publish graph records, enable quote providers, ingest real material, or complete Markets.

Typed equity, cryptoasset and network nodes remain separate canonical identities. Exact issuer/network companion versions, endpoint node versions and shared edge versions are retained in the same evidence history. The new typed_graph_relationship candidate branch preserves existing event-only candidates. Assessment context adds all exact endpoint/edge/companion change positions to the existing dependency machinery.

The private reader checks current workspace membership, exact retained observation membership and six operation scopes per material (rights/privacy × retention/analysis/excerpt_display). It holds the existing publication/revocation fence through the read, uses sorted material identities, verifies stored Unicode spans through the existing retained_excerpt function, and returns only bounded private projections. The trusted server seam injects the authenticated user and configured source; client inputs contain identities and valid time only.

Private shared graph records require a protected suppression discriminator. Restrictive policies exclude them even when old permissive raw policies exist. Public edges cannot expose private endpoints. The known definer aggregate explicitly excludes private nodes/edges and private endpoint citations. Installation refuses additional catalog-discoverable exposed dependent views; dynamic SQL/functions and the full production surface inventory still require review. This is not a general publication eligibility flag and there is no private-to-public promotion function.

Fixture parity is limited: existing hypothesis fixtures supply actual native evidence/workspace/permission functions, strengthened with the observed seven-type node check and endpoint UUID foreign-key/non-self-edge constraints. The actual survivor currently lacks the old historical edges_type_check; the fixture does not pretend otherwise. Public/source schema, owners, grants and all live readers have not been fully mirrored. Production installation remains BLOCKED.

The SQL and fixture presently qualify bounded typed path mechanics in both directions, with synthetic equity/crypto and indirect relationships. Recorded supported assessments are not independent validation of real-world claims or method calibration. All source passages, identities, authority receipts and relationships in tests are synthetic. Source-root lineage is explicitly unqualified; no independent-source count is inferred. Broader context is not fabricated. Current time filters are valid/event time, not an as-known-then reconstruction.

Remaining before complete initial-release Markets: independent review; complete canonical alias/temporal ambiguity and method-admission qualification; verified source/root lineage and exact attribution obligations; production-authoritative rights/privacy binding for market materials; public publication decision bindings (existing generic assessments stay private and public validator remains unchanged); full exposed-reader inventory; real-data equity/crypto/indirect journeys; reusable asset card, dedicated workspace and supported two-way shared-surface navigation; explicit deployment authorization. Quotes, TradingView and CoinMarketCap remain separately gated. No new fee, credential, provider, production write or owner-device project file is authorized here.

Execution evidence and failures remain on the draft PR. A green mechanism test does not establish production rights, publication or complete Markets.

## Bounded discovery and deterministic identity inputs
The recursive input is capped at sixteen typed candidates whose exact capture, endpoint, edge and optional companion versions are retained by the requested workspace observation. The seventeenth fails closed before recursion; final response LIMIT is not the work bound. Adjacent hops must share the exact retained node version, not only node UUID. Candidate fan-out is covered by a transaction-rolled-back native fixture. Request timestamps require explicit offsets and at most PostgreSQL microsecond precision; relative, date-only, timezone-less and finer timestamps are rejected before authentication/query.

Private path projections retain permission-checked node ID/version/type/name, issuer/network ID/version/type/name, asset validity/identifier and aliases tied to the asset version. The existing retained excerpt provides exact material hash/version, input position, field and span; it does not prove primary-source/root independence or complete rights/attribution metadata. Those absent provenance contracts remain BLOCKED. Empty paths do not provide a standalone qualified asset card, and no browser endpoint is implemented. This is a backend prerequisite, not completed MK-1 or a Markets workspace.
