# Private Markets authenticated transport qualification

This branch adds an isolated Request/Response handler, explicitly configured HTTPS transport and disposable view-scoped client over the frozen private retained SQL reader. SQL, roles, grants and public endpoint actions are unchanged. There is no deployed entrypoint or default endpoint.

The handler requires a server-configured exact HTTPS-origin allowlist, source namespace, verified bearer-authentication function and parameterized query function. Browser JSON contains only investigation/workspace/asset/event IDs and an explicit-offset microsecond timestamp. Cookies and caller identity/rights/reviewer/observation authority flags are rejected. Authentication must be verified server-side; JWT decoding/user-editable metadata is not an acceptable implementation. No provider authentication is configured by this package.

Requests are limited to4096bytes, responses to1048576bytes; streams and operations have deadlines/abort handling. No cookies, cache, redirects, token persistence or automatic retries. Client disposal/new requests suppress late successes and denials even if an injected adapter ignores AbortSignal. Expected observation ID is supplied from the already-loaded workspace context for result matching, never sent as database authority.

The strict private mapper rejects unknown keys, promoted publication/lineage/history flags, mismatched scope/observation/time, malformed endpoint-version adjacency and Unicode span lengths. It retains issuer/network and shared-node versions, aliases, actual excerpt material hashes/spans and nullable source metadata. Unsafe/non-HTTP(S)/userinfo URLs are suppressed rather than made actionable. Date-only published/identity metadata stays text; no midnight event time, rights-cleared state, provenance or independent root is invented. Response instant equivalence uses the existing marketInstant parser with at most microsecond precision; request timestamp spelling is retained for display.

Meaningful sanitized outcomes distinguish401authentication,403access/origin denial,400malformed requests,409evidence unavailable or resource saturation, and503transient/invalid backend responses. No raw SQL/Auth diagnostics or private payload is logged.

Native qualification invokes actual Request -> handler -> createPrivateMarketsReader -> PostgreSQL PREPARE/EXECUTE as mip_hypothesis_gateway, then the strict client mapper. Authentication is an explicit synthetic bearer-to-fixture-user mapping; rights grants remain the existing synthetic admin-created native fixture. This is not real provider verification, browser networking/CORS enforcement, deployment, publication, or real-source authority qualification. Unknown production readers, source-root lineage, full attribution/rights, zero-path asset card, larger corpus scale and complete Markets UI remain blocked/incomplete as documented by the base package.
