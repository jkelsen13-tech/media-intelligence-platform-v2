# MapLibre attribution security qualification

Base: 267c36dec6c39afafbab4494efffc83d01a6a752.
MapLibre 4.7.1 falls in the affected range of CVE-2026-85061 /
GHSA-jrc7-96c5-q579. World View's fallback uses an external OpenFreeMap style
and MapLibre AttributionControl; production exploitation is not asserted.

The branch pins MapLibre 6.4.1, the maintainer's patched release. Its sanitizer
snapshots attributes before removal, preventing adjacent unsafe attributes from
being skipped. Required attribution is preserved. The upgrade requires namespace
ESM import and explicit bundled worker setup: Vite's worker&url pipeline emits
the worker plus its shared imports as a same-origin asset under the Pages base.
No new map provider, geography, data feed, continuous rendering or backend write.

The lockfile is generated by npm in GitHub Actions with package scripts disabled
and reviewed before commit. Only MapLibre's dependency closure changes. New
MapLibre geojson-vt (ISC), vt-pbf (MIT), mlt (MIT OR Apache-2.0), updated style-spec
(ISC), point-geometry (ISC), unitbezier (BSD-2-Clause), vector-tile and pbf
(BSD-3-Clause) remain permissively licensed. MapLibre retains BSD-3-Clause.
Distributed license notices and package integrity metadata remain required.

Permanent browser regression uses the actual built application in Chromium and
WebKit at 1280/390px, also on the live page after release. Cesium import failure
is injected only in the disposable browser; MapLibre must mount, load the real
style and start its same-origin bundled worker. Navigation and exact camera
restoration preserve the canonical route; unsupported fidelity controls remain off.
A second intercepted style supplies harmless synthetic malicious-attribution
markup. A separate positive control proves its event marker executes without
sanitization. The actual control must remove event attributes, preserve the
required attribution link and never execute the marker. No test payload reaches
a source server, stored evidence or deployed site file.

Full Golden tests/builds and all existing preview/live regression steps remain
required. Final results belong on the PR; this document is not a passing-run
claim. Earlier dependency triage's zero-critical statement is historical.
Other build-tool advisories remain separate remediation work. Markets PR121
remains pending until this security qualification passes and current-head
verification permits its own merge. Backend consolidation is incomplete.
