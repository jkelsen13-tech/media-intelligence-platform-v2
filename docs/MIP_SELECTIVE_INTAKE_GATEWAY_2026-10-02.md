## Existing owners and contracts

`createInvestigationApiHandler` imports the core `createSelectiveIntakeHandler` and injects the existing `authenticate` and `workspaceRpc` plus a narrow `selectiveIntakeRpc`. The route is `investigation-api/selective-intake`. Its only commands are `read`, `receipt`, `declare`, and `reconsider`. The existing workspace owner supplies exact retained immutable observations and assignment role. The core computes the unchanged pure declaration/reconsideration result on the server and the core SQL appends a durable private annotation; request JSON cannot provide actor identity, a trusted observation, or a computed result.

The one added fixed server RPC is `mip_investigation_selective_intake_v1` on the existing validated backend origin, using the existing server credential boundary, redirect refusal, and 15-second abort budget. Opaque server keys have their invalid bearer header stripped only on fixed server RPC targets; the user's Auth header is preserved for the existing verified `/auth/v1/user` call. No function-to-function fan-out, arbitrary RPC proxy, new credentials, or new backend target exists.

`createInvestigationBackend` maps `investigation-selective-intake` to the registered route and exposes `.selectiveIntake` using the unchanged core SDK adapter. It invokes the installed SDK with the current session on each request. Optional snapshotted `{expectedUserId}` metadata becomes the existing `X-MIP-Expected-User` refusal precondition. Only verified Auth supplies identity; a mismatched expected account refuses before any owner RPC. The core success envelope `{data, authenticated_user_id}` binds receipts and reads to that verified actor, and the adapter refuses a mismatched actor. The outer durable receipt is `persisted:true`; its unchanged canonical `result` remains `persisted:false` with its original declaration hash/provenance. Neither persistence nor actor binding establishes source rights, registered policy, truth, or execution.

A missing selective RPC/configuration returns unavailable. No fallback, source acquisition, automatic decision, reassessment, dispatch, promotion, or public reader was added. Current App, Auth lifecycle, Following UI, public readers, Markets, deployment entry point, historical migrations, and previous gateway manifests are preserved.
