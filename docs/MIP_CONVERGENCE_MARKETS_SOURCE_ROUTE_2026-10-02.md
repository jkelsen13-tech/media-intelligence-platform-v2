# Initial-release Markets source route — 2026-10-02

## Outcome and qualification boundary

This lane adds the required dedicated Markets route to the native application. It provides typed asset choice, identity details, retained reporting, evidence paths, separate clocks, honest price availability, accessible disclosures, and canonical navigation. The default application has **no authorized typed asset directory**, so it explicitly displays directory/price unavailability. No runtime synthetic assets, ticker inference, inferred relevance, provider request, publication decision, credential, or backend endpoint is introduced.

This is an initial-release SOURCE foundation and tested supplied-source integration seam. It does **not** close Markets release requirements. A trusted publication/reader owner must supply an authorized typed projection before real asset search and reporting are available. Fixtures establish deterministic behavior, not real asset mappings or source admission. The earlier temporal lane's statement that there was no Markets UI is superseded by this route implementation; its source/provider qualification limits remain.

Baseline: `0d378f58ea732bbde2d3e8a1d5c66b70cf6a75a5`. Branch: `codex/mip-convergence-markets-foundation-20261002`. No push, merge, deployment or release.

## Supplied-source lookup contract

`createMarketSourceLookup(snapshot)` is a deterministic reader of an **already authorized** source projection. The current backend composition root does not provide one. The sole declared seam is an App prop or backend-owner `publicData.marketSourceSnapshot`; it is not a public JSON endpoint, token scheme, directory implementation or permission system.

A supplied projection declares contract `mip-markets-authorized-directory-v1`, available status, nonblank retained version, exact explicit-zone `validAt` and `observedAt`, at most 200 typed assets and at most 200 proposed reporting paths. Asset identity/version/publicity/alias validity failures or duplicate canonical IDs reject the directory atomically. Input is copied and frozen. Search is bounded to 120 characters, has no blank-query toy asset list, and commits no identity. Lookup uses an exact canonical ID and kind. Reporting must match the same retained asset version and exact valid instant; it is revalidated for rights, support and corrections. A different inspection instant cannot borrow the snapshot's paths.

The eventual source owner must establish authoritative identity, retained revisions, audience, publication policy, reporting rights and correction/version semantics before wiring real records into this seam. Caller-authored `publiclyEligible` values are not authority. Fixture `available` status is explicitly synthetic and proves only the client contract. There is no new source owner, transport, provider adapter, source-byte acquisition or metadata admission.
