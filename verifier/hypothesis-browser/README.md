# Synthetic hypothesis interface verification

This disposable GitHub-hosted check bundles the actual generation ledger and its validator with three explicitly synthetic records. It does not start the application, configure Auth, call a backend, fetch source material or invoke a worker. Every page network request is aborted and any attempted request fails verification.

Chromium and WebKit exercise keyboard inspection and recovery preparation at 1280, 768, 390 and 320 pixels, reciprocal recovery links, suppression of duplicate recovery preparation, permission-denied clearing and logout clearing. Only synthetic rendered screenshots and sanitized results enter logs. This is interface verification, not production Auth, an independent review, human approval, complete composer coverage or semantic qualification.

Run in the existing remote disposable environment after npm ci and installing the repository's pinned browser-verifier version: MIP_BROWSER_PACKAGE=/remote/disposable/mip-browser node verifier/hypothesis-browser/run.mjs. The workflow uses contents:read only and no secrets.
