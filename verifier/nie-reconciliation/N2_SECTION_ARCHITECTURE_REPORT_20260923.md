## Change and rationale

`scripts/mipNieParentCustody.mjs` extends existing lossless serialization and fingerprint helpers. It requires the exact project/schema, field allowlists, sorted per-row UUIDs and canonical hashes, membership closure count/key digests, schema digest, snapshot ID, source fence, manifest hash, bounded bytes and deterministic pages. Page run IDs contain the full manifest hash, so a changed snapshot cannot silently reuse a prior job. Its source adapter must read closure and every page under one pinned read-only repeatable-read transaction and verify all hashes before any destination write. This is an **interface requirement**, not proof that a hosted connector supplies it. Maximum configured bytes are 128 MiB; maximum page size is 100 rows.

The initially tested generic `public.mip_legacy_graph_v1` finish path unexpectedly revalidated **all** staged dependent families, potentially changing unrelated endpoint checks, reviews, decisions and conflicts. Independent High review rejected that writer scope. The corrected candidate `supabase/qualification/nie-parent-custody/001_scoped_finish.sql` adds `legacy_graph_staging.finish_nie_parent_job` as a private SECURITY INVOKER function with explicit service-role execute and browser/PUBLIC revokes. It validates the exact NIE parent job, run, page hash, active lease, source family and fields, reuses native staging/version/job-result helpers, completes the job and records its event **without** the global dependency validator. The function remains **UNAPPLIED** on qik and needs separate authority and target preflight. The adapter requires `destination.withPageTransaction`: enqueue, exact-run claim and scoped finish share one destination connection and transaction per page, preventing a generic worker from seeing a newly queued uncommitted page. Private readback occurs after commit.

Expected destination write families for an accepted page are `legacy_graph_staging.import_jobs`, `job_events`, `staged_records`, `payload_versions` and, on conflict, `record_conflicts`; it reads mapping/collision owners. The isolated candidate does not call global endpoint revalidation or write public News, Source Comparison, graph, review or publication tables. Incomplete/conflicted pages remain explicitly incomplete, retained and source-qualified; exact retries use the same manifest-bound IDs. Unknown adapter exception details are reduced to fixed redacted codes. Reconstruction returns verified current lossless JSON and provenance, not native relational/vector restore or fabricated older versions.

Architecture after in isolation: **NIE pinned current parent selection → exact private manifest/pages → atomic scoped qik staging job → private row/version readback → current JSON reconstruction**. Live NIE/qik architecture is unchanged. N1's empty membership tables and current publication rules are unchanged.
