## Concrete producer and consumer

1. A current scoped reviewer binds original capture/job/article/content identity plus exact body presence-kind/hash and URL hash through `review_source`. Validation uses the originally named completed import/capture, verifies the complete original JSONB hash, and refuses a superseded capture using the existing current capture order. Body string, JSON null and missing remain distinct. Admission does not create access.
2. `set_source_access` explicitly grants/revokes this private supplemental source access. Changed disposition increments its revision. Re-enabling access cannot resurrect an old projection.
3. `review_citations` records a complete reviewed set, including explicit reviewed-empty, with original body UTF8 byte boundaries/hash and finite court_doc/agency_release/other classifications. These are newly reviewed native classifications, not fabricated historical citation rows or model/provider scores. Missing review is never treated as no findings. Additional, revoked or superseded reviews invalidate the old projection.
4. `inspect_context` and `review_context` bind exact arc category/root/type and the complete bounded milestone id/key/status set. Their deliberately retained selected context is used for projection replay and current equality. Baseline milestone notes are not copied because this private adapter does not mutate public milestone state.
5. `prepare` accepts exact generation/input hash/output hash/current accepted-private score review plus source/citation/context review identities. It invokes the actual unchanged current native score reader and requires candidate decision with no hard rejections. It then derives bounded private node/source/event/edge/milestone display values and journals one immutable display payload plus a separate metadata dependency manifest. An identical ID retry rechecks current authority and returns the same metadata receipt; a conflicting retry refuses.
6. `review` records an exact private pending/accepted/revoked disposition, and `read_current` revalidates the entire native score/source/access/citation/context chain before returning the private display. Neither can_decide nor accepted_private means privacy, rights, approval or publication eligibility.

The private node/event/edge field arithmetic and category/outlet/citation-confidence branches follow the recovered projector. The milestone evaluator is the exact recovered body with only its function namespace/name changed; no heuristic rewrite. No historical projector is blindly invoked against current public rows. There are no foreign-object upserts: private identities are append-only, and public projection collision/ownership/public attach remain required later integration.

An original capture's full body is used transiently for milestone evaluation and citation span validation. It is never retained in the new tables, receipts, dependency manifests or reviews. Private display intentionally retains bounded title/summary/outlet/URL/date fields for its concrete scoped reader. It is not metadata-only. Historical retraction baseline/evidence behavior remains covered separately by the real historical fixture; no new baseline copy is needed here.

## Current change and resource semantics

The context includes a count of immutable selected public-relation source_changes under the common collector/publication fence. This conservative version binds changes to articles/arcs/nodes/milestones even when values later return to their previous representation. It can invalidate on unrelated changes to those relations; it is deliberately not presented as a per-row revision or full-row digest. It reads metadata only and does not copy existing historical rows. A stale private display remains recorded but is refused by the current reader.

The original complete cohort/current capture/entity/field policies remain enforced by the unchanged current score reader. Whole-operation accounting conservatively reserves the native generation's reviewed max_total_bytes/max_hash_work_bytes, first reserving2MiB of supplemental headroom before any source reconstruction/hash work, then checking measured original capture, transient source/context expansion and output allowances. Combined limits remain8MiB and128MiB hash work. A native policy already consuming those entire maxima cannot qualify this larger operation without a separately reviewed profile adjustment. No native limit is waived or silently changed. Synthetic qualification explicitly chooses4MiB/64MiB for the native fixture profile to leave bounded headroom.

The vector branch is explicitly absent and no centroid is updated. Existing native enqueue has no vector producer; a real versioned vector384 producer identity/input binding is required before enabling the optional vector branch. No mutable article embedding or invented capture field substitutes for it.
